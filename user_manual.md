# User Manual: AI Awareness Survey Report Generator

This guide explains how to use the survey report generation tool in [AI_Survey_Report_Generator.html](AI_Survey_Report_Generator.html). The tool helps you turn survey response data into a presentation-ready deck, with audience-specific summaries and export options.

## 1. Overview

The application is designed to:
- import a survey export
- build a report deck from the survey data
- tailor content for different audiences
- review and edit slides
- export to PowerPoint or print/PDF

The interface is organized into four main areas:
- Top bar: main actions and audience selection
- Left panel: deck settings and slide list
- Center: slide preview/stage
- Right panel: content and slide customization options

## 2. Getting started

### Open the tool
1. Open [AI_Survey_Report_Generator.html](AI_Survey_Report_Generator.html) in a modern web browser.
2. The page loads with the default report configuration and slide deck.
3. If the app has not yet loaded survey data, use the import action to bring in a survey export.

### Recommended browser
- Use the latest version of Chrome, Edge, or another modern browser.
- Keep the browser window wide enough to see the three-panel layout comfortably.

## 3. Importing survey data

### New report from survey
1. Click the button labeled "New report from survey" in the top bar.
2. Select or upload the survey export file.
3. Confirm the import and let the app build the report deck.

### Expected file types
The app is designed for Excel-based survey exports, typically in .xlsx format.

### Important notes
- Confirm that the file includes the expected survey question columns and response data.
- If the file is missing required fields, the app may produce incomplete or inaccurate reporting output.
- Always verify the imported data before sharing the report.

## 4. Deck settings

The left panel includes the "Deck settings" section.

Use this area to control the report metadata and overall deck structure, such as:
- program name
- report title
- subtitle / audience language
- survey period or reference information
- survey number or label
- date metadata
- data source and generation date

These settings are important because they appear in the deck and should be reviewed before export.

## 5. Audience options

The top bar includes an audience selector with options such as:
- Champions
- Leadership

Switching audiences changes how the same survey data is described and framed for different audiences.

Use this feature to:
- tailor messaging for different stakeholders
- highlight different insights for different reader groups
- produce a more relevant report without rebuilding from scratch

## 6. Slide navigation and editing

### Slides panel
The left panel includes a list of slides in the deck.

For each slide you can:
- include or exclude it from the deck
- reorder slides
- duplicate a slide if needed for alternative views
- focus on a slide by selecting it

### Preview stage
The center stage shows the currently selected slide.

The slide preview lets you:
- review the generated layout
- check for clarity and accuracy
- spot areas that need to be edited or refined

### Stage controls
At the bottom of the stage, use the navigation buttons to:
- move to the previous slide
- move to the next slide
- review slides in sequence

## 7. Right panel controls

The right panel contains slide-specific controls and content settings.

Depending on the selected slide, this panel may include:
- spotlight selections
- key insight toggles
- emphasis settings
- design options
- callout / takeaway controls
- summary values or narrative variations

Use this area to refine the presentation style and emphasize the points that matter most.

## 8. Reset and defaults

The app includes a reset function for restoring the report to its default state.

Use this when:
- you want to start over from the original template
- a report has become too customized or inconsistent
- you want to remove ad hoc edits quickly

Note: Resetting will remove changes you have made and should be used intentionally.

## 9. Print and PDF options

### Print / PDF
1. Click "Print / PDF" in the top bar.
2. Use the browser print dialog.
3. Choose Save as PDF or print the report directly.

This is useful when you need:
- a portable copy
- a quick shareable file
- a document for review outside of PowerPoint

## 10. PowerPoint export

### Export PowerPoint
1. Click the button labeled "Export PowerPoint".
2. The tool generates a PowerPoint version of the current deck.
3. Save the file to your preferred location.

This is the main output for presentation use and is designed to be easier to distribute than a browser-based deck.

## 11. Saving a copy

The top bar includes a "Save copy" action.

Use this to:
- keep a local copy of the current report state
- preserve layout changes and edits
- work from a saved version while continuing to refine the deck

## 12. Draft review and verification

This tool includes a clear warning that output is AI-assisted and should be reviewed before sharing.

Before finalizing or distributing a report:
- verify all figures and wording
- check whether interpretation matches the survey data
- confirm that the selected audience framing is appropriate
- review all labels, dates, and survey metadata

> Important: A person should review the report before it is used for external communication or decision-making.

## 13. Best practices

### Before building the report
- Confirm the survey file is the correct version.
- Check that the survey metadata is complete and accurate.
- Decide which audience the report is intended for.

### While reviewing slides
- Check whether the narrative is balanced and fair.
- Ensure the deck does not overstate a result.
- Review wording for clarity and professionalism.

### Before export
- Validate all headline findings.
- Confirm there are no missing labels or empty data points.
- Review the deck in both audience modes when relevant.

## 14. Troubleshooting

### The report does not look right
- Re-import the survey file.
- Confirm the deck settings are correct.
- Select the correct audience.
- Recheck whether the intended slide was selected.

### The output seems incomplete
- Review the imported data file for missing columns or blanks.
- Check whether the deck includes all intended slides.
- Reset to defaults if the report has become inconsistent.

### Export does not open or behaves unexpectedly
- Refresh the page.
- Re-open the survey file.
- Save a copy and retry the export.
- Make sure the browser is updated to a modern version.

## 15. Suggested workflow

A good working flow is:
1. Open the tool and load the survey data.
2. Review the deck settings and metadata.
3. Check the audience mode.
4. Review each slide in sequence.
5. Adjust emphasis and text if needed.
6. Save a copy.
7. Print or export the final report.
8. Verify findings before sharing.

## 16. Summary

This tool is designed to help users convert survey data into polished, presentation-ready outputs with minimal manual formatting. Its strengths are:
- fast assembly of a report deck
- audience-specific framing
- ready-made export options
- slide review and adjustment tools

Its main requirement is human review. The tool helps create the draft, but the content should still be checked before final use.

For support or future enhancements, maintain the source file and related data files together so the report stays consistent with the intended survey dataset.
